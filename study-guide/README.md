# Study guide

`gelation_transfer_explained.tex` — a from-scratch learning walkthrough of the
whole project: the science, the code logic, the statistics, every figure, and the
problems/decisions behind the choices. Written for understanding, not as a paper.

## Building

Uses only standard, portable packages (`graphicx`, `amsmath`, `booktabs`,
`xcolor`, `framed`, `listings`, `enumitem`, `hyperref`, `microtype`, `geometry`).
The `figures/` folder here holds the figure PDFs it embeds, so the folder is
self-contained.

```bash
pdflatex gelation_transfer_explained.tex
pdflatex gelation_transfer_explained.tex   # 2nd pass resolves the ToC + refs
```

On Overleaf: upload `gelation_transfer_explained.tex` and the `figures/` folder,
then compile. The figures also live in `../figures/` (regenerated by
`experiments/06_figures.py`), which the preamble's `\graphicspath` also checks.
